# opstobiasdale-notes

DevOps engineer · Python and boto3

学习用的示例项目

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/opstobiasdale-notes.git
cd opstobiasdale-notes
cargo build --release
```
